# Acid Lime Portfolio

Build a high-end, editorial, clean white portfolio website for a professional Video Editor following the attached specification.

Key requirements and updates:
- In the Direct Video Hub section, provide 4 pre-filled mock video entries (YouTube embed IDs / MP4s) with clear buttons so clicking any title instantly switches the active player.
- Make the acid lime/amber accent pop sharper on hover buttons and tag badges, while keeping the main container cards ultra-clean white with 1px borders.
- Strictly adhere to the color and aesthetic guidelines: pure white (#FFFFFF) and off-white/warm gray (#F9F9FB, #F3F3F5) background with crisp deep charcoal/black typography (#111111, #1A1A1A). Absolutely NO blue tones or cool slate tints. High-contrast electric acid lime (#D4FF00 / #CCFF00) paired with punchy warm amber/vermilion accents for hover states, badges, and active pills.
- Include all sections: Sticky Minimalist Nav, Hero with stat counters and quick reel trigger, Filterable Project Gallery with slide-out side drawer for project details, Direct Watch Video Link Hub with 4 pre-filled mock entries and instant switcher, Creative Toolkit & Workflow grid, and Contact/Socials footer with one-click copy email.
